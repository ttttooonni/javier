# Javier Rodríguez · Barbate 2027 — PWA de campaña (borrador)

Versión orientativa para revisar tono, estructura y formatos de comunicación.
Las propuestas se basan en iniciativas públicas del grupo socialista y declaraciones del candidato;
se sustituirán por el programa definitivo.

## Estructura
- `index.html` — app completa (datos en el bloque `<script>`: EJES, HECHO, TRAY, TEAM, AGENDA, SLOGANS)
- `sw.js` — caché offline. **Sube `VERSION` en cada publicación.**
- `manifest.webmanifest` + `icons/` — instalable en Android e iOS
- `assets/` — foto optimizada (WebP) e imagen para compartir (`og.jpg`)

## Pendiente de la candidatura
Programa 2027, lista, agenda real, redes y canal de WhatsApp, responsable de datos (RGPD/LSSI),
backend del formulario, identidad visual oficial y URL absoluta en `og:image` al publicar.

## Publicación
GitHub Pages: subir el contenido de esta carpeta a la raíz del repositorio y activar Pages.
